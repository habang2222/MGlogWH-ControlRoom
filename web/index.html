EVENT RULES

JSON 조건식 규칙

0 / 8

조건은 {"all":[...]}, {"any":[...]}, {"not":{...}} 또는 {"field":"path","op":"eq","value":"/etc/shadow"} 형식입니다. 최대 8개 규칙, 규칙당 조건 노드·실행 토큰 각 24개, 깊이 4단계입니다. in·not_in 목록은 최대 4개 값입니다. 각 규칙에 priority와 overload_policy를 지정합니다. 실제 유효성은 MGlogWH 설정 검증기가 확인합니다. 격리 면제는 로그 무손실을 보장하지 않습니다.

설정을 불러오는 중입니다.
